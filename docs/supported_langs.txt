# CToon supported-language registry - drives the tab bar + tab content of
# docs/index.html.in (see docs/CreateDocs.cmake).
#
# One language per line, pipe-delimited:
#   <folder> | <display name> | <icon kind> | <icon value>
#
# folder       - subdirectory name under docs/ (also the "<panel>-<folder>"
#                id/data-tab suffix used in the generated HTML).
# display name - label shown on the tab button.
# icon kind    - "fa"  : a Font Awesome class string (icon value below).
#                "svg" : a named inline SVG glyph, resolved by
#                        CreateDocs.cmake's ICON_SVG_<value> variable
#                        (currently only "layers", the generic
#                        block/document glyph shared by C, C++, Zig and
#                        Julia - none of which has a suitable brand icon
#                        in Font Awesome's free set).
# icon value   - the FA class string, or the SVG glyph name.
#
# Order here is the display order everywhere: CLI is pinned first (it's
# the tool most users reach for first), the rest are alphabetical by
# display name.
#
# Each folder must contain three fragment files, each holding the raw
# inner HTML for one tabbed panel:
#   <folder>/index-docs.txt    - API reference card (docs panel)
#   <folder>/index-install.txt - installation instructions (install panel)
#   <folder>/index-example.txt - quick-start code sample (example panel)

cli    | CLI    | fa  | fa-solid fa-terminal
c      | C      | svg | layers
cpp    | C++    | svg | layers
go     | Go     | fa  | fa-brands fa-golang
julia  | Julia  | svg | layers
matlab | MATLAB | fa  | fa-solid fa-square-root-variable
python | Python | fa  | fa-brands fa-python
rust   | Rust   | fa  | fa-brands fa-rust
zig    | Zig    | svg | layers
